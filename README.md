# PRISM FLUX – Digital Innovation Studio

A responsive website for a digital innovation studio, built using HTML5 and CSS3. The project focuses on modern UI design, clean layouts, and presenting technology-driven services through a visually engaging interface.

## Overview

PRISM FLUX is a frontend website concept for a digital studio. It showcases digital services, technical capabilities, and company information through a structured, multi-section layout.

The design combines modern styling, technology-inspired imagery, and organised content to create a consistent user experience.

## Features

- Modern landing page with a clean visual layout
- Responsive page structure for different screen sizes
- Services section highlighting web development, app development, and cloud solutions
- Skills section displaying technical capabilities
- Technology-themed images and visual elements
- Contact form layout for visitor enquiries
- Footer with company information and social link placeholders

## Technologies Used

- HTML5 – Website structure and content
- CSS3 – Styling, layouts, and visual effects
- JPG – Website image assets

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sairohitmungara/frontend-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd frontend-project
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` using the Live Server extension or directly in a browser.

## Project Objective

The objective of this project was to build a technology-focused website while practising HTML structure, CSS styling, responsive layouts, and frontend development fundamentals.
